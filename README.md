# Système Éveil

Application d'entraînement personnelle, en un seul fichier HTML, sans dépendance
ni serveur. Quêtes journalières, suivi calorique et de composition corporelle,
jeûne, sommeil, plan de course et paliers de progression.

Toutes les données restent dans le navigateur de l'appareil (`localStorage`).
Rien n'est envoyé nulle part.

**Application : https://squysh.github.io/systeme-eveil/**
